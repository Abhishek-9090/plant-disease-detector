# 🌿 Plant Leaf Disease Detection System

An AI-powered web application that detects plant leaf diseases from uploaded images using Deep Learning and Computer Vision techniques. The system helps farmers and users identify plant diseases quickly and provides treatment recommendations for better crop health management.

---

## 🚀 Features

- 🌱 Detect plant leaf diseases from images
- 🧠 CNN-based Deep Learning model
- 📸 Image upload and prediction system
- 📊 Confidence score for predictions
- 💊 Medicine and treatment suggestions
- ⚡ Interactive Streamlit web application
- 📱 User-friendly interface

---

## 🧠 How It Works

1. **Image Upload** → User uploads plant leaf image  
2. **Preprocessing** → Resize and normalize image  
3. **Model Prediction** → CNN model predicts disease class  
4. **Result Generation** → Display disease name and confidence score  
5. **Recommendation** → Suggest medicine/treatment options  

---

- **Language:** Python

- **Computer Vision:** OpenCV  
- **Libraries:** NumPy, Pandas, Matplotlib
